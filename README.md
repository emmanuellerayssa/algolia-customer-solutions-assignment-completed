# Algolia Solutions Assignment

### Technical Assignment - Part One 
This part was addressed by creating the python script named `transform_data.py`.

## How to Run

To execute the script, open the command line and use the following command, replacing `"directory-path-to-product.json"` with the full path to your `products.json` file:

```bash

python transform_data.py --file_path "directory-path-to-product.json\products.json"

```
