# Algolia Search Discovery

<b>Algolia</b> is a tech company that helps businesses provide an exceptional user experience by offering a fast, hosted search engine that can be seamlessly integrated into their apps or websites. More info about Algolia on their [website](https://www.algolia.com) .

# Project Goal
In this project, I show you how to integrate Algolia’s Search and Insights APIs within the context of an online shop (Spencer and Williams) to deliver personalized results to users. It’s also an opportunity to experiment with HTML and CSS to create an attractive front-end for the shop, while showcasing my JS development skills.

**PS:**: For the complete context of this project, please visit the following [repository](https://github.com/emmanuellerayssa/Search-Discovery).

## How to Run

To execute the script, open the command line and use the following command, replacing `"directory-path-to-product.json"` with the full path to your `products.json` file:

```bash

python transform_data.py --file_path "directory-path-to-product.json\products.json"

```
